# Translate 0.4.0

**GPT-6 ASTRA**

## 简体中文

项目和桌面程序更名为 Translate。首次启动会迁移 Mi OCR Desk 的设置和加密 API 配置。升级前请从托盘退出旧程序。

- 「翻译」页位于「截图识别」上方。
- `Ctrl+Alt+Y` 翻译其他应用中选中的可复制文字，包括 PDF 文本。
- `Ctrl+Alt+E` 打开输入翻译悬浮窗，默认输出英文。`Ctrl+Enter` 翻译，`Esc` 关闭并取消请求。
- 软件设置与 API 设置分为两页，四个全局快捷键均可修改。
- 所有翻译入口沿用 API 设置中的系统提示词、模型和推理强度，支持 `{targetLanguage}`。

软件包为 `Translate-0.4.0-win-x64-portable.zip`，自带 .NET。OCR 可复用原有 `OcrRuntime`，或使用 0.3.3 的独立模型包。将模型目录放在 `Translate.exe` 旁即可。翻译通过自行配置的在线 API 完成。

受复制限制的 PDF、扫描图片或权限较高的目标应用可能无法读取选区，可以粘贴文字或使用截图识别。自动检查使用模拟接口，PDF 划词、全局快捷键和实际界面由用户手动验证。

## English

The application and projects are now named Translate. Existing Mi OCR Desk settings and encrypted provider profiles migrate on first launch. Exit the previous app through its tray before upgrading.

- A Translation page appears above Capture.
- `Ctrl+Alt+Y` translates selected copyable text from other applications, including PDF readers.
- `Ctrl+Alt+E` opens a compact input popup with English output by default. `Ctrl+Enter` translates and `Esc` closes/cancels.
- Software settings and API settings are separate pages. All four global shortcuts are configurable.
- Every translation entry point uses the saved provider, model, reasoning and shared system prompt with `{targetLanguage}` substitution.

The software ZIP includes .NET. Reuse the existing `OcrRuntime` or the separate 0.3.3 model package beside `Translate.exe`. Translation uses the configured online provider. Selection requires an application that allows copying. Automated checks use simulated APIs, while actual PDF selection, shortcuts and layout are checked manually.
