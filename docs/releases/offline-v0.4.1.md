## 独立软件包与模型包 / Separate software and model packages

将软件包与模型包解压到同一目录，使 `Translate.exe` 与 `OcrRuntime` 并排。已有模型目录可直接复用，校验各自附带的 SHA256 文件。

Extract the software and model packages into the same directory, with `Translate.exe` beside `OcrRuntime`. Existing model directories can be reused. Verify each download with its accompanying SHA256 manifest.
