## 独立软件包与模型包 / Separate software and model packages

软件与模型分别提供。将软件 ZIP 和模型 ZIP 解压到同一目录，使 `Translate.exe` 与 `OcrRuntime` 并排，按照附带校验文件分别核验。已有模型目录可以继续复用。

Software and models are packaged separately. Extract them into the same directory with `Translate.exe` beside `OcrRuntime`, and verify the archives using the accompanying checksum files. Existing model directories can be reused.
