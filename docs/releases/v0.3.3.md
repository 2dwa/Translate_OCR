# Mi OCR Desk 0.3.3

**Project attribution / 项目署名：GPT-6 ASTRA**

## 简体中文

首次公开发布，提供类 iOS 风格的 Windows 本地 OCR 与翻译工作台。

- `Ctrl+Alt+O`：截图识别；`Ctrl+Alt+T`：截图后自动识别并翻译。均可在偏好设置修改。
- OCR 悬浮窗、原文/译文对照、复制与导出；`Esc` 关闭悬浮窗并取消任务。
- OpenAI / DeepSeek / 兼容服务，模型列表、推理强度和独立加密的供应商密钥。
- 内嵌设置、自定义输出语言、托盘后台、静默启动、可选开机启动。
- 可手动关闭 OCR 模型，彻底退出自动卸载模型并关闭本程序启动的识别服务。

下载 `MiOCRDesk-0.3.3-win-x64-portable.zip`，依据 `SHA256SUMS.txt` 校验并解压。新电脑先运行 `Setup-OCR.cmd` 下载并验证 Ollama 与 Xiaomi OCR 模型，再运行 `MiOcrDesk.exe`。首次模型安装联网下载约 3.4 GB，完成后 OCR 可离线使用；便携 ZIP 不含模型权重。已有模型可直接关联目录。

系统要求：Windows 10 2004+ / Windows 11 x64；程序内置 .NET，无需安装 Python。程序未进行 Authenticode 签名。更新前请从托盘退出旧版。

## English

First public release of an iOS-inspired Windows desktop client for local Xiaomi OCR and configurable text translation.

Features include floating capture results, bilingual comparison, copy/export, a capture-and-translate shortcut, Esc-to-close, provider-specific encrypted settings, OpenAI/DeepSeek model lists and reasoning controls, tray operation, optional login startup and model cleanup on exit.

Download and verify the portable ZIP, extract it, run `Setup-OCR.cmd` once on a new computer, then launch `MiOcrDesk.exe`. First-time model setup downloads approximately 3.4 GB from pinned upstream sources and verifies SHA256 hashes. The ZIP does not include model weights. OCR is offline after setup; translation requires your provider API. Windows 10 2004+ / Windows 11 x64; .NET is included. Binaries are unsigned.
