# Translate 0.4.1

**项目署名 / Project attribution — GPT-6 ASTRA**

## 简体中文

Mi OCR Desk 更名为 **Translate**。本次发布整合独立翻译工作区、划词翻译、输入悬浮窗、设置拆分及布局调整。

### 下载与升级

- 软件约 72 MB，自带 .NET。[Translate 0.4.1 软件 ZIP](https://github.com/2dwa/Translate_OCR/releases/download/v0.4.1/Translate-0.4.1-win-x64-portable.zip) · [软件 SHA256](https://github.com/2dwa/Translate_OCR/releases/download/v0.4.1/SHA256SUMS.txt)
- 截图 OCR 使用独立模型包，约 2.05 GB。已有模型目录可直接复用。[Xiaomi OCR 模型 ZIP](https://github.com/2dwa/Translate_OCR/releases/download/v0.3.3/MiOCRDesk-0.3.3-win-x64-models.zip) · [模型 SHA256](https://github.com/2dwa/Translate_OCR/releases/download/v0.3.3/SHA256SUMS-OFFLINE.txt)

升级前从系统托盘退出旧程序，再运行 `Translate.exe`。首次启动自动迁移 Mi OCR Desk 的设置和加密 API 配置，已启用的登录启动项会更新程序路径。

文字翻译只需软件包及自行配置的在线 API。使用截图 OCR 时，将模型包解压到软件目录，使 `Translate.exe` 与 `OcrRuntime` 并排。模型沿用已发布的 0.3.3 独立包，各下载文件使用对应的 SHA256 校验。

### 功能与调整

- 「翻译」页位于「截图识别」上方，翻译页及悬浮窗默认左侧原文、右侧译文，与截图页共用模式切换、复制、导出、翻译按钮及进度样式。
- `Ctrl+Alt+Y` 翻译 PDF 或其他应用中选中的可复制文字。小窗先显示读取进度，后台读取期间保留原应用焦点，支持取消等待。
- `Ctrl+Alt+E` 打开输入翻译悬浮窗，默认输出英文。`Ctrl+Enter` 翻译，激活的小窗中按 `Esc` 可关闭并取消任务。
- 「软件设置」和「API 设置」分为两页。四个入口的目标语言分别保存，所有翻译入口共用供应商、模型、推理强度和系统提示词，支持 `{targetLanguage}`。
- 软件设置按「启动与后台 → 快捷翻译 → 截图与识别 → 各入口目标语言」排列。快捷翻译与截图快捷键统一为左侧说明、右侧固定宽度输入框。
- `Ctrl+Alt+O` 截图识别，`Ctrl+Alt+T` 截图并翻译，四个全局快捷键均可修改并检查冲突。

### 验证与使用范围

33 项自动检查覆盖窗口构造、左右布局、独立目标语言、旧配置迁移、快捷键冲突回滚、取消和模拟接口。实际 PDF 选区、混合 DPI 和快捷键体验由用户手动验证。选中文字需要目标应用允许复制，扫描图片可使用截图 OCR。

支持 Windows 10 2004+ / Windows 11 x64。程序包含 .NET 10.0.14，发布文件未进行 Authenticode 签名。

## English

Mi OCR Desk is now **Translate**. This release combines the dedicated translation workspace, selected-text translation, quick-input popup, separate settings pages and layout refinements.

### Downloads and upgrade

- Software ZIP, approximately 72 MB, including .NET. [Download Translate 0.4.1](https://github.com/2dwa/Translate_OCR/releases/download/v0.4.1/Translate-0.4.1-win-x64-portable.zip) · [Software SHA256](https://github.com/2dwa/Translate_OCR/releases/download/v0.4.1/SHA256SUMS.txt)
- Separate OCR model package, approximately 2.05 GB. Existing model directories can be reused. [Download Xiaomi OCR model](https://github.com/2dwa/Translate_OCR/releases/download/v0.3.3/MiOCRDesk-0.3.3-win-x64-models.zip) · [Model SHA256](https://github.com/2dwa/Translate_OCR/releases/download/v0.3.3/SHA256SUMS-OFFLINE.txt)

Exit the previous app through its tray before launching `Translate.exe`. Existing settings and encrypted provider profiles migrate on first launch, and an enabled login-startup entry is updated to the new executable path.

Text translation uses the software package and your configured online API. For screenshot OCR, extract the model package beside the executable so that `Translate.exe` and `OcrRuntime` are side by side. This release references the separately published 0.3.3 model asset. Verify each download with its matching SHA256 manifest.

### Features and changes

- The Translation page appears above Capture. Translation pages and popups share the screenshot result component, defaulting to side-by-side text with matching modes, copy/export actions and progress feedback.
- `Ctrl+Alt+Y` translates selected copyable text from PDF readers and other apps. Reading progress appears first while the source app keeps keyboard focus. Clipboard work runs on a cancellable background thread.
- `Ctrl+Alt+E` opens the input popup with English output by default. `Ctrl+Enter` translates and `Esc` closes/cancels an active popup.
- Software settings and API settings are separate pages. Screenshot, selection, workspace and quick-input translation have independent target languages. All entries use the shared provider, model, reasoning and system prompt with `{targetLanguage}` substitution.
- Quick translation sits below Startup and background. Its shortcut rows match the capture rows with descriptions on the left and fixed-width controls on the right.
- `Ctrl+Alt+O` captures and recognizes. `Ctrl+Alt+T` captures and translates. All four global shortcuts are configurable with conflict checks and rollback.

33 automated checks cover construction, layout, language isolation, migration, hotkeys, cancellation and simulated APIs. Real PDF selection, mixed-DPI layout and desktop shortcuts are manually verified. Selected-text translation requires an app that permits copying. Screenshot OCR handles image-based text.

Windows 10 2004+ / Windows 11 x64 is required. .NET 10.0.14 is included. Release binaries are unsigned.
